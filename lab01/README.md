# Лабораторная работа №1: Развертывание БД в Docker и создание схемы

## 📝 Описание задания
Здесь кратко опишите суть вашей первой практики (например: "Создание реляционной базы данных для учета продаж и наполнение её фактами").

## 🚀 Как запустить проект

1. Убедитесь, что у вас установлен и запущен **Docker Desktop**.
2. Перейдите в папку с лабораторной работой:
   ```bash
   cd lab01
   ```
3. Запустите контейнер с базой данных:
   ```bash
   docker compose up -d
   ```

## 🛠 Подключение к базе данных
* **Инструмент:** DBeaver / DataGrip
* **Хост:** `localhost`
* **Порт:** `5432` (или тот, что указан в вашем yml)
* **Пользователь/Пароль:** (укажите ваши данные из docker-compose)

## 📁 Структура SQL-скриптов
* `01_schema.sql` — Скрипт для создания таблиц и связей.
* `02_data.sql` — Скрипт для наполнения таблиц тестовыми фактами.
